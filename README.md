# Lab 12 – Desarrollo Web: Seguridad SQL, Procedimientos Almacenados e Integración PHP-MySQL

## Instrucciones

1. Haz **fork** de este repositorio.
2. Lee el documento del estudiante completo antes de comenzar.
3. Crea la rama `lab12-apellido-nombre` (con tus datos reales).
4. Sigue el paso a paso de Git del documento.

## Estructura del repositorio

```
ejercicio1/        ← Sentencias preparadas (tema 4.5)
ejercicio2/        ← Procedimientos almacenados (tema 4.6)
ejercicio3/        ← Aplicación web integrada (tema 4.7)
evidencias/        ← Capturas de pantalla (mínimo 4)
autograde.php      ← No modificar
.github/workflows/ ← No modificar
```

## Configurar tu base de datos antes de comenzar

Ejecuta en phpMyAdmin el archivo `ejercicio1/setup.sql`.

## Tu semilla personal

Abre `ejercicio1/config_semilla.php` y coloca los **últimos 3 dígitos de tu cédula**.
